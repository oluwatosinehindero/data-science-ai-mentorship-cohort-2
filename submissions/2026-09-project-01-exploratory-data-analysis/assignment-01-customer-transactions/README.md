# Assignment 01 - Customer and Transaction Data Analysis Submissions

This folder contains mentee submissions for Assignment 01.

## Required Submission

Each mentee should submit:

- `customer_transactions_analysis.ipynb`
- `report.md` or a PDF report

## Folder Structure

Each mentee must create a folder using their GitHub username.

For example, if your GitHub username is `marydata`, your work should be placed inside:

`submissions/2026-09-project-01-exploratory-data-analysis/assignment-01-customer-transactions/marydata/`

Your folder should contain something similar to:

```text
marydata/
├── customer_transactions_analysis.ipynb
└── report.md
```

## Important
Do not upload:
- customers_data.csv
- transactions_data.csv
These datasets were provided privately and should not be committed to GitHub.

Do not commit directly to the main branch.

Create your assignment branch, add your work, and create a Pull Request when you are ready for mentor review.
