# Assignment 02 - Fake News Data Analysis Submissions

This folder contains mentee submissions for Assignment 02.

## Required Submission

Each mentee should submit:

- `fake_news_analysis.ipynb`
- `report.md` or a PDF report

## Folder Structure

Each mentee must create a folder using their GitHub username.

For example, if your GitHub username is `marydata`, your work should be placed inside:

`submissions/2026-09-project-01-exploratory-data-analysis/assignment-02-fake-news-analysis/marydata/`

Your folder should contain something similar to:

```text
marydata/
├── fake_news_analysis.ipynb
└── report.md
```
## Important
Do not upload:
- Fake (1).csv
- True.csv
The datasets were already provided by the mentor and should not be duplicated in the submission folders.

Do not commit directly to the main branch.

Create your assignment branch, add your work, and create a Pull Request when you are ready for mentor review.
