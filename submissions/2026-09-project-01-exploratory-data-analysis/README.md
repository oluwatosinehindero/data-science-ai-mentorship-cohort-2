# September 2026 - Project 01 Submissions

This folder contains mentee submissions for Project 01 of the Data Science and Artificial Intelligence Mentorship Programme.

## Project

Exploratory Data Analysis

## Assignments

Every mentee must complete both assignments:

1. Customer and Transaction Data Analysis
2. Fake News Data Analysis

## Submission Rules

Each mentee must submit their work inside a folder named with their GitHub username.

Do not commit work directly to the `main` branch.

Each assignment should be completed on a separate branch and submitted through a Pull Request for mentor review.

Do not upload the raw datasets to this repository.

The mentor will review each Pull Request before the work is merged into the `main` branch.
