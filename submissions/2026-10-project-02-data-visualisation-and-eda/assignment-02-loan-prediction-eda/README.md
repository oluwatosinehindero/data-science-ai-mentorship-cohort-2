# Assignment 02 - Loan Prediction Data Analysis Submissions

This folder contains mentee submissions for the October Python data-analysis assignment.

## Required Submission

Each mentee should submit:

- `loan_prediction_analysis.ipynb`;
- findings report in Markdown or PDF format;
- personal `README.md`.

## Personal Folder

Create a folder using your GitHub username.

For example:

`submissions/2026-10-project-02-data-visualisation-and-eda/assignment-02-loan-prediction-eda/marydata/`

A completed submission may look like:

```text
marydata/
├── README.md
├── loan_prediction_analysis.ipynb
└── loan_prediction_report.pdf'''

Do not commit directly to main.

Create a separate assignment branch and submit your work using a Pull Request.
