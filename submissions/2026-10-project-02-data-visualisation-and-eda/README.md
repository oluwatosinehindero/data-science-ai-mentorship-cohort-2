# October 2026 - Project 02 Submissions

This folder contains mentee submissions for Project 02 of the Data Science and Artificial Intelligence Mentorship Programme.

## Project

Data Visualisation and Exploratory Data Analysis

## Assignments

Every mentee must complete both assignments:

1. Movie Analytics Power BI Dashboard
2. Loan Prediction Data Analysis with Python

## Submission Rules

Each mentee must submit their work inside a folder named with their GitHub username.

Each assignment should be completed using a separate assignment branch.

Do not commit directly to the `main` branch.

When an assignment is complete, create a Pull Request for mentor review.

Do not merge your own Pull Request.
