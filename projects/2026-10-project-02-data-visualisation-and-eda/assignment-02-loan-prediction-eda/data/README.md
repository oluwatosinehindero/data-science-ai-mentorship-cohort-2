# Dataset Access - Loan Prediction Analysis

The Loan Prediction dataset contains two files:

- `train.csv`
- `test.csv`

The files were provided to mentees by the mentor for the October Python data-analysis assignment.

## Training Dataset

The training dataset contains 614 records and includes the target variable:

`Loan_Status`

## Test Dataset

The test dataset contains 367 records and does not include `Loan_Status`.

## Important

The datasets contain missing values in several variables.

Identifying, investigating and appropriately handling these values forms part of the assignment.

The focus of this assignment is exploratory data analysis rather than building a machine-learning prediction model.
