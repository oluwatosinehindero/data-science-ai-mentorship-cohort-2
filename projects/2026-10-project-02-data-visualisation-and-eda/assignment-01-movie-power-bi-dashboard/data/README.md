# Dataset Access - Movie Analytics

The dataset required for this assignment is:

- `BEST MOVIE.xlsx`

The dataset was provided to mentees by the mentor for the October Power BI assignment.

## Dataset Overview

The dataset contains 1,000 movie records and includes information such as:

- genre;
- production company;
- director;
- movie title;
- rating;
- theatre release date;
- Rotten Tomatoes rating;
- movie length;
- global box-office revenue; and
- budget.

Mentees should investigate and clean the data before developing the dashboard.

Do not assume that every value in the dataset is correct simply because it is populated.
