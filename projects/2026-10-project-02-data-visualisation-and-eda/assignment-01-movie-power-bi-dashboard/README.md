# Assignment 01 - Movie Analytics Power BI Dashboard

## Objective

The purpose of this assignment is to develop an interactive Power BI dashboard that transforms movie data into meaningful information, insights and recommendations.

The focus is not simply on creating attractive charts. Your dashboard should help a user understand the performance and characteristics of the movies contained in the dataset.

## Dataset

The assignment uses the Best Movie dataset.

The dataset contains information about 1,000 movies, including:

- genre;
- production company;
- director;
- movie title;
- movie rating;
- theatre release date;
- Rotten Tomatoes rating;
- movie length;
- global box-office revenue; and
- budget.

## Assignment Tasks

### 1. Understand the Data

Before creating the dashboard:

- review the dataset;
- understand what each variable represents;
- check the data types;
- identify potential data-quality problems; and
- determine which measures and dimensions will be useful for the analysis.

### 2. Clean and Prepare the Data

Use Power Query or other appropriate Power BI tools to clean and prepare the data.

Investigate:

- column names;
- data types;
- invalid or unusual values;
- duplicate records;
- missing information;
- inconsistent categories; and
- any other data-quality issues you identify.

Do not automatically remove unusual values.

Investigate them first and document important cleaning decisions.

### 3. Create Relevant Measures

Create appropriate measures or calculated fields where useful.

Examples may include:

- Total Global Box Office;
- Total Budget;
- Average Movie Budget;
- Average Rotten Tomatoes Rating;
- Number of Movies;
- Average Movie Length;
- Profit or estimated return;
- Box Office to Budget ratio; and
- other useful measures you identify.

### 4. Develop the Power BI Dashboard

Create a clear and interactive dashboard that communicates meaningful insights.

Your dashboard may explore areas such as:

- movie performance by genre;
- box-office performance;
- budget versus box-office revenue;
- Rotten Tomatoes ratings;
- production companies;
- directors;
- movie ratings;
- movie release trends;
- movie length; and
- other patterns you identify.

You are encouraged to decide which visualisations best communicate the story contained in the data.

### 5. Dashboard Design

Your dashboard should:

- have a clear title;
- use appropriate visualisations;
- have readable labels;
- use consistent formatting;
- avoid unnecessary visual clutter;
- contain appropriate filters or slicers;
- display important KPIs clearly; and
- guide the viewer towards the most important insights.

### 6. Analysis and Interpretation

Do not simply display charts.

Explain what the charts reveal.

Consider questions such as:

- Which genres appear to generate the greatest box-office revenue?
- Which production companies perform strongly?
- Is greater movie budget associated with greater box-office revenue?
- Are highly rated movies necessarily the highest-grossing movies?
- Which directors or movie categories stand out?
- Are there noticeable patterns over time?
- Are there unusual or potentially problematic values in the data?

You are encouraged to explore beyond these questions.
