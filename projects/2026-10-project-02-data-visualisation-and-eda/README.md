# Project 02 - Data Visualisation and Exploratory Data Analysis

**Month:** October 2026  
**Programme:** Data Science and Artificial Intelligence Mentorship  
**Mentor:** Oluwatosin Ehindero

## Project Overview

This is Project 02 of the three-month Data Science and Artificial Intelligence Mentorship Programme.

The October project focuses on developing practical skills in data preparation, exploratory data analysis, data visualisation and communicating findings to support decision-making.

Every mentee must complete both assignments.

## Project Assignments

### Assignment 01 - Movie Analytics Power BI Dashboard

Develop an interactive Power BI dashboard using the Best Movie dataset.

The dashboard should communicate meaningful information about movie performance, ratings, genres, production companies, directors, budgets and box-office performance.

Mentees must also provide a report explaining their findings, insights and recommendations.

### Assignment 02 - Loan Prediction Data Analysis with Python

Use Python to clean, preprocess and explore the Loan Prediction datasets.

The objective at this stage is exploratory data analysis and understanding the factors associated with loan outcomes.

A machine-learning prediction model is not required for this assignment.

Mentees must provide a Python notebook and a simple report explaining their findings.

## Learning Objectives

By completing this project, mentees should be able to:

- inspect and understand unfamiliar datasets;
- identify and address data-quality issues;
- clean and preprocess data appropriately;
- perform exploratory data analysis;
- create meaningful data visualisations;
- develop an interactive Power BI dashboard;
- identify important patterns and relationships;
- distinguish findings from interpretations;
- communicate insights clearly; and
- make evidence-based recommendations.

## Expected Deliverables

### Assignment 01

Each mentee should submit:

- Power BI dashboard file (`.pbix`);
- dashboard screenshot or PDF export;
- simple findings and recommendations report.

### Assignment 02

Each mentee should submit:

- Python/Jupyter/Google Colab notebook (`.ipynb`);
- simple findings report in Markdown or PDF format.

## Important

The aim of the project is not simply to create charts.

Mentees should be able to explain:

- why particular cleaning decisions were made;
- why particular visualisations were selected;
- what the results mean;
- which findings are supported by the data; and
- how the insights could support decision-making.

Focus on understanding the data and communicating a clear analytical story.
