# Project 01 - Exploratory Data Analysis

**Month:** September 2026  
**Programme:** Data Science and Artificial Intelligence Mentorship  
**Mentor:** Oluwatosin Ehindero

## Project Overview

This is the first project of the three-month Data Science and Artificial Intelligence Mentorship Programme.

The purpose of this project is to develop practical experience in data cleaning, preprocessing, exploratory data analysis and communicating insights using Python.

At this stage, the focus is on understanding the data rather than building machine learning models.

Each mentee must complete both assignments in this project.

## Project Assignments

### Assignment 01 - Customer and Transaction Data Analysis

Analyse the customer and transaction datasets to understand the quality, structure, characteristics and patterns within the data.

### Assignment 02 - Fake News Data Analysis

Analyse the Fake and True news datasets to understand the characteristics, quality and patterns within the news data.

## Learning Objectives

By completing this project, mentees should be able to:

- load and inspect datasets using Python;
- identify and address data-quality issues;
- clean and preprocess data appropriately;
- perform exploratory data analysis;
- create meaningful visualisations;
- identify patterns, trends and unusual observations;
- communicate findings clearly; and
- document analytical work in a reproducible notebook.

## Expected Deliverables

Each assignment requires:

1. A completed Python/Jupyter/Google Colab notebook (`.ipynb`).
2. A simple report summarising the main findings.

The report may be submitted as a Markdown file (`report.md`) or PDF.

## Important

The objective is not simply to produce charts or complete Python code.

Mentees should understand:

- what the data represents;
- why each cleaning decision was made;
- why each analysis was performed;
- why particular visualisations were selected; and
- what conclusions can reasonably be drawn from the results.

Enjoy the process, explore the data carefully, and focus on understanding what your analysis is telling you.
